# Puissance 4

Jeu de Puissance 4 en C# avec interface graphique, réalisé dans le cadre
de la SAÉ 2.2 (BUT Informatique, IUT d'Amiens).

## Fonctionnalités
- Partie à deux joueurs ou contre une IA
- Personnalisation de l'interface
- Paramétrage de la partie : nombre de colonnes et de lignes de la grille,
  nombre de jetons à aligner pour gagner, temps imparti pour jouer un coup
- Détection de la victoire (lignes, colonnes, diagonales)
- Interface graphique

## Technologies
C#, .NET, Visual Studio, [Windows Forms / WPF : à préciser]

## Lancer le projet
1. Cloner le dépôt
2. Ouvrir `Puissance4.slnx` dans Visual Studio
3. Lancer avec F5

Projet réalisé en binôme. Je me suis occupé de la personnalisation de
